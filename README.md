# homebrew-reel-studio

Homebrew tap for [Reel Studio](https://github.com/murathany7/reel-studio): make marketing reels, ads and posts with
code, for any brand, with Claude Code.

```bash
brew install murathany7/reel-studio/reel-studio
reel-studio init      # copy the kit and skills into this folder and install the renderer
```

Brings Node and ffmpeg. Rendering also needs Google Chrome; Blender is optional, for 3D plates.

The formula is maintained in the main repo (`packaging/homebrew/reel-studio.rb`) and copied here on each release
with `packaging/update-formula.sh`.
